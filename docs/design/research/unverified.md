# Thông tin chưa xác minh được

Nhãn `[CHƯA XÁC MINH]`. Lý do chung: sandbox chặn phần lớn host ngoài (proxy trả 403 hoặc DNS không phân giải) — chỉ `developer.android.com`, `proxy.golang.org`, `repo1.maven.org`, `registry.npmjs.org`, `hub.docker.com` và công cụ tìm kiếm truy cập được. GitHub API bị chặn (không có quyền repo) nên không đọc được trạng thái archived/issue của thư viện.
